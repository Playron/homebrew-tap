# homebrew-tap

Homebrew casks for apps in [Playron/homelab](https://github.com/Playron/homelab).

```sh
brew install --cask playron/tap/sbx
```

| Cask | App |
|---|---|
| `sbx` | [sbx](https://github.com/Playron/homelab/tree/main/apps/sbx), an Azure Service Bus explorer. Apple Silicon only. |

The `version` and `sha256` in each cask are bumped automatically by the release workflow in the
homelab repo when a new tag is pushed.
